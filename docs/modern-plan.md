## 关键机制（存档数据核实）

- 俄罗斯"西方派2"传统：城市 +15% 科技（苔原城市 +20%）——**需要 CITY_IS_CITY**，镇子无效
- "农奴制改革"传统：城市 +15% 产能（-15% 增长代价）——同样需要城市
- 转城费用 = 800 + 1000×已有城市数 − 50×镇人口，**抢来的镇翻倍**
- → 策略：先研究市政再转城；自建古城转城便宜（~1300金），抢来的翻倍（~2600金）
